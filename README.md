# METEOR CANYON

ガウシアンスプラットで撮ったガンプラを操り、奥へ奥へと飛ぶブラウザゲーム。シーンはタイトル画面で切り替える（← → / ◀ ▶）。

- **隕石帯** — 宇宙空間で、いろいろな形と大きさの隕石と、ときどき飛んでくる彗星をかわす
- **要塞の溝** — 巨大な宇宙要塞の表面に刻まれた溝。曲がりくねり、急カーブや連続カーブ、狭い所も多い溝を、壁や障害物（壁から張り出したブロック・梁・床の壁・すき間の門）、浮遊する機雷に触れずに飛ぶ

**遊ぶ:** https://fumiakim.github.io/test_splat_game/

## 操作

| 操作 | キーボード | ゲームコントローラー | タッチ |
|---|---|---|---|
| 移動 | ← → ↑ ↓ / W A S D | 左スティック / 十字キー | 画面をドラッグ |
| ブースト | Space（長押し） | Ⓐ / RB / RT（長押し） | BOOST ボタン |
| スタート・リトライ | Space / Enter | Ⓐ | タップ |
| シーン切り替え（タイトル） | ← → | 十字キー ◀ ▶ / LB・RB | ◀ ▶ ボタン |
| ポーズ | P / Esc | START | — |
| 音のオン・オフ | M | BACK | SOUND ボタン |

ゲームコントローラーは標準配置（Xbox / PlayStation など）。当たると振動します。ブラウザの決まりで、コントローラーのボタンだけでは音が鳴り始めないので、最初に一度クリックかキーを押してください。

## URL のオプション

- `?scene=trench` / `?scene=space` — そのシーンで始める（ふだんは前回選んだシーン）
- `?rocks` — 隕石の形（7 種類）と大きさ（4 階級）の見本。Space・クリックでページ切り替え
- `?canyon` — 渓谷の中を飛ぶ旧モード
- `?hitbox` — 自機の当たり判定（スキャンの点から作った小さな球の集まり）を緑の光で表示

## つくり

- `index.js` / `index.sog` / `settings.json` — SuperSplat Viewer の書き出し（PlayCanvas）
- `game.js` — ゲームの進行・操作・カメラ
- `world.js` — 隕石・彗星・要塞の溝（コースの形・障害物・壁の当たり）の出現と当たり判定。難易度は SPACE / TRENCH の表
- `body-shape.js` — 自機の当たり判定の形（スキャンの点を小さなマスに分けて球を置く）
- `rock-shapes.js` — 隕石の形の生成（じゃがいも型・細長い型・双子型・平たい板状・角ばった破片・クレーター型・ごつごつ塊）
- `world-gl.js` / `space-fx.js` — WebGL2 の描画（溝の壁と床の金属パネル・岩・箱・光・背景の粒・スラスターの炎）
- `splat-light.js` — 自機（スプラット）のライティング（太陽・リムライト・スラスターの光・彗星の光・被弾の赤）
- `hud.js` / `audio.js` — 画面表示と効果音（Web Audio で合成。要塞にぶつかった音だけ `sounds/hit-metal.mp3` の録音）
